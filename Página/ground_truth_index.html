Configure a variável STORAGE_BACKEND no arquivo .env para alternar entre os backends.

💾
Local (padrão)
Armazena na pasta ground_truth_dataset/ do servidor
STORAGE_BACKEND=local
🪣
AWS S3
Bucket S3 escalável. Configure as credenciais no .env
STORAGE_BACKEND=s3
☁️
Google Cloud Storage
Bucket GCS com credenciais de conta de serviço JSON
STORAGE_BACKEND=gcs

Exemplo de .env

GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxx

# ── escolha um: local | s3 | gcs ──
STORAGE_BACKEND=s3

# ── AWS S3 ──
AWS_BUCKET_NAME=transcreva-ground-truth
AWS_REGION=us-east-1
AWS_ACCESS_KEY_ID=AKIA...
AWS_SECRET_ACCESS_KEY=xxxxxxxxxxxxxxxx

# ── Google Cloud Storage ──
GCS_BUCKET_NAME=transcreva-ground-truth
GOOGLE_APPLICATION_CREDENTIALS=/caminho/para/credenciais.json

Instalar dependências

pip install flask flask-cors groq boto3 google-cloud-storage jiwer python-dotenv
